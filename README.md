Пока что системно ничего не реализовано, просто раскидано чтоб работало, в ближайшем будущем внятно реализую

Реализовано:
- Базовый пайплайн (в него входят 
вершинные и фрагментные шейдеры, 
буферы (VAO/VBO),
текстурные юниты, 
отрисовка)
- Камера (WASD)
- Рендеринг текста через FreeType
- ImGui отладочное окно (пока просто есть в качестве видное интеграции ImGui)
- Матричные преобразования (модель, вид, проекция) через GLM

Будет реализовано:
- Цельная система
- Парсинг obj файлов
- Освещение
- Рабочий пользовательский интерфейс
- Много чего всякого бонусом для кармы

V0.1

Создана вроде вменяемая система, удобно управляемая UI. Можно добавлять модели в .obj (считываются позиции вершин, UV, нормали, также поддерживается индексирование, дабы шейдеры сильно не потели), материалы, к ним текстур сколько угодно, но только если шейдеры поддерживают их, само собой, удалять через ПКМ всё это дело в UI. По навигации: движение на WSAD, повороты с левым ctrl + ПКМ. Лайтнинг добавлю в ближайшее время, только завалы свои разгребу
